# Screenshots di Twixy

Salva in questa cartella gli screenshot reali catturati dall'app in esecuzione usando esattamente questi nomi file, cosi' il `README.md` principale li mostrera' automaticamente su GitHub:

- `main-ui.png` — Schermata principale (ricerca canali / player live + chat con emote).
- `multiview-grid.png` — Modalita' Multi-Live a griglia con piu' stream contemporanei.
- `clip-studio.png` — Clip Studio durante il ritaglio/salvataggio in locale di una clip MP4.
- `drops-center.png` — Centro Drops attivi con stato campagne e auto-claim.

Suggerimento rapido su Windows: premi `Win + Shift + S` sulla finestra di Twixy (prima assicurati di aver oscurato eventuali dati personali se necessario) e salva i 4 PNG qui dentro.
